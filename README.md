# 3d-prints

My 3D printing projects for a Bambu Lab A1 (0.4 mm nozzle, black and white PLA).

```
skills/openscad-print/   Copilot skill: OpenSCAD model, approve, Bambu Studio queue
bin/                     build.sh (export, previews, size report), click.js
designs/<name>/          my own OpenSCAD models, each with a README.md
favourites/<name>/       downloaded models I like, each with a README.md
```

Each project README records purpose, source URL, author, licence, and print settings (filament, plate, time).
